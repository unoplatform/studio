# Uno Platform Studio — Feature Specifications

Feature specifications for the Uno Platform Studio plugin, skills and tooling in this repository. Each spec lives in its own numbered folder with a `spec.md`, an optional `spec-brief.md`, and a `checklists/` folder.

## Specification Process

Specs follow the same structure as the other Uno Studio repositories: prioritized, independently testable user stories with Given/When/Then acceptance scenarios; numbered functional requirements (`FR-nnn`); measurable success criteria (`SC-nnn`); assumptions, design decisions, dependencies and explicit out-of-scope items.
